## TwoSiteBoolean

This Lean project formalizes the `\ell = 1` case of a two-site Boolean
expansion.

$$
\prod_{i=1}^{\ell+1}\Delta_{y_i}\left[\frac{1}{D}\right]
=\left(\prod_{i=1}^{\ell+1} y_i\right)
\sum_{\pi\in\mathfrak{S}_{\ell+1}}
\frac{1}{
D_{\varnothing}\,
D_{\{Y_{\pi_1}\}}\,
D_{\{Y_{\pi_1},Y_{\pi_2}\}}\cdots
D_{\mathcal{Y}}
}\,.
$$
